# Прогнозирование стоимости недвижимости

Командная работа: сравнение моделей регрессии для прогноза цен на жильё и Streamlit-приложение с формой прогноза и справкой.

Авторы: Низметдинова Камила, Рухтина Полина

## Что сделано

**Данные** — датасет турецкого рынка недвижимости: убрали мусорные столбцы и ошибочные строки, заполнили пропуски, обработали выбросы, перевели цены в доллары и прологарифмировали цену с площадью.

**Признаки** — one-hot для типа жилья, отопления, города и типа объявления, target encoding для района, числовой признак комнат, проверка мультиколлинеарности через VIF.

**Модели** — сравнили Ridge, Decision Tree и Random Forest, гиперпараметры подбирали через GridSearchCV. Лучший результат у Random Forest: MAE 0,244, RMSE 0,419, MAPE 4,09%, R² 0,973.

**Приложение** — Streamlit с вкладками: прогноз цены по параметрам объекта и справка по полям и ограничениям модели.
